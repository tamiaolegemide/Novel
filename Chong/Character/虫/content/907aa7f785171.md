# 军衔
*宋朝武官最特殊的地方，是[b]“官阶”和“实际职务”常常不是一回事[/b]。也就是说，一个人头衔里带“节度使”“观察使”“防御使”，不一定真的在管那个州；带“都指挥使”“统制”“都监”，才更可能是他实际掌兵的职务。

### 一、先看三个概念

>> 决定品级、俸禄、服色、升迁资历 <<

>> 太尉、武功大夫、修武郎、承信郎 <<

>> **正任官、遥郡官** <<

>> 高级武臣荣誉虚衔，代表地位 <<

>> 节度使、承宣使、观察使、防御使、团练使、刺史 <<

>> **差遣 / 军职** <<

>> 真正掌兵、治事的职务 <<

>> 殿前都指挥使、都统制、统制、钤辖、都监 <<


### 二、武阶官大小：政和改制后的主流体系

北宋政和二年以后，武阶官逐步改成以[b]“大夫、郎”[/b]为主的体系，南宋绍兴年间又整理为[b]六十阶[/b]。

从高到低大致是：

**太尉**
武阶之首，正二品。

**横班正使（大夫）**
如：通侍大夫、正侍大夫、宣正大夫、履正大夫、协忠大夫、中侍大夫、中亮大夫、中卫大夫、翊卫大夫、亲卫大夫、拱卫大夫、左武大夫、右武大夫。
约正五品至正六品。

**诸司正使（大夫）**
如：武功大夫、武德大夫、武显大夫、武节大夫、武略大夫、武经大夫、武义大夫、武翼大夫。
一般正七品。

**横班副使（郎）**
如：正侍郎、宣正郎、履正郎、协忠郎、中侍郎、中亮郎、中卫郎、翊卫郎、亲卫郎、拱卫郎、左武郎、右武郎。
约正七品至从七品。

**诸司副使（郎）**
如：武功郎、武德郎、武显郎、武节郎、武略郎、武经郎、武义郎、武翼郎。
从七品。

**大使臣**
敦武郎、修武郎。
正八品。

**小使臣**
从义郎、秉义郎、忠训郎、忠翊郎、成忠郎、保义郎、承节郎、承信郎。
从八品到从九品。

**无品尉勇**
如进武校尉、进义校尉、下班祗应、进武副尉、进义副尉等。
属于未入正式品阶的底层武阶。

简单记：**太尉 > 大夫 > 郎 > 使臣 > 尉勇**。


### 三、正任官和遥郡官：高级武臣的“贵官”

正任官是武臣荣誉序列里很高的虚衔，通常要皇帝特旨授予，不参与普通磨勘升迁。

从高到低：

**节度使**：从二品

**承宣使**：原称节度观察留后，正四品

**观察使**：正五品

**防御使**：从五品

**团练使**：从五品

**刺史**：从五品

[b]遥郡官[/b]则是在武阶官基础上，加带刺史、团练使、防御使、观察使、承宣使等名号，但品级仍按本官阶算，也不实际赴任。只有“落阶官”后，才正式转入正任官序列。

### 四、实际军职：看“差遣”才知权力

武官真正管兵，要看差遣。

中央最高统兵系统是[b]三衙[/b]：

殿前司都指挥使

侍卫马军司都指挥使

侍卫步军司都指挥使

他们统兵，但调兵权在[b]枢密院[/b]。

地方和军中常见实职有：

**都统制、副都统制**：南宋方面军、大军区级统兵官

**统制、统领**：军级、师级统兵官

**正将、副将、准备将**：基层统兵官

**钤辖、都监、监押**：地方驻军、路州级军政官

**指挥使、都头**：更基层军官

### 五、北宋前期还有武散官

政和改制前，宋朝还沿用唐代遗留的武散官，如：

骠骑大将军

辅国大将军

冠军大将军

云麾将军

昭武校尉

陪戎副尉

共三十一阶，从一品到从九品下都有。但政和以后，这些散官逐渐被新武阶官体系取代。
